Using Sidecar

Choose and find files

Choose a folder for each pane. Select a file and press Open or double-click it. Search includes subfolders. Use Show in folder to jump to a result’s location.

Copy and move

Use Copy or Move to send the selection to the other pane’s current folder. Drag between panes to copy. Hold Shift while dropping to move.

Edit and delete

Open a text file to edit it or open an image to preview it. Use Ctrl/⌘+S to save, F2 to rename, or Delete to open the delete confirmation. Deleted items are removed permanently.
